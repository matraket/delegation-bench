# Results

Aggregated, privacy-safe results of the delegation benchmark. Generated by `node scripts/export-results.mjs` from the gitignored `.bench/` directory; do not edit by hand. No raw session file, event log, agent home or package copy is included, and no absolute path. The method is in [`docs/METHODOLOGY.md`](../docs/METHODOLOGY.md) and the reading of these numbers in [`docs/RESULTS.md`](../docs/RESULTS.md).
